AuditionMusic5

Docs

AuditionMusic5 plays Audition music in your browser. This page explains every feature and how to use it, from first login to downloading tracks.

Getting started

  1. Open the homepage and press Sign up to create an account, or Log in if you already have one.
  2. You can sign in with an AM5 account or with Google.
  3. After logging in, the song list loads automatically.

Login is required to play music and to download MP3 or OGG. Downloading the original TBM/ABM file works without login.

Browsing the library

Server selector

Use the server dropdown to switch between regional Audition catalogs. Each server has its own song list, so the table changes when you switch.

Categories

The tabs above the list filter the catalog:

  • All Music - the full catalog of the selected server.
  • Ballroom Music - ballroom tracks only.
  • Guitar Music - guitar tracks, which have a separate backing and note audio.
  • Playlist - only the tracks you saved.

Search and sort

  • Type in the search box to filter by singer, song title, file name, or BPM.
  • Press the clear button inside the search box to reset the filter.
  • Click the Singer, Music Name, or BPM column header to sort. Click again to reverse the order.
  • Press Show more at the bottom to load the next part of the list.

NEW badge

A NEW marker in the New column means the track was recently added at the source server.

Playing music

Press the play button on any row. The player bar appears at the top with these controls:

  • Previous and Next - move between tracks in the current list.
  • Play / Pause - the large center button.
  • Shuffle - play the list in random order.
  • Repeat - cycles through off, repeat all, and repeat one.
  • Seek bar - drag to jump inside a track. The time label follows the cursor.
  • Volume - drag the slider; the percentage is shown next to it.

The first play of a track takes longer because the audio has to be prepared. Later plays of the same track are faster.

Guitar Music mode

Guitar tracks have two audio parts: backing and note. In the Guitar Music category, the row can show a both button. It plays the backing and note audio together, the way the mode works in the game.

Playlist

  1. Press the playlist icon in the Action column to add a track.
  2. Press it again to remove the track.
  3. Open the Playlist tab to see only your saved tracks.

Your playlist is linked to your account and works across servers, so you can keep Indonesia, Vietnam, and other tracks in one list.

Free accounts can save up to 30 tracks. VIP accounts can save up to 100 tracks.

Downloads

Each row has download buttons depending on the track type:

  • tbm / abm - the original file from the source server. No login needed.
  • mp3 - converted audio, works on any device. Login required.
  • ogg - converted audio at the original quality. Login required.

Downloads are personal use only. Do not resell or reupload the files as another public library.

Offline access

Recently played audio is stored on your device. If the connection drops or you open the site without internet, tracks you already played can still be played again on the same device and browser.

Mobile and installing the app

The site works on desktop and mobile browsers.

iOS

Install on iPhone / iPad

Add AuditionMusic5 to your Home Screen from Safari.

  1. Tap the Share button (square with an arrow) in Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add to finish.

The Share button is in the top or bottom toolbar. If Add to Home Screen is missing, open this page in Safari.

Android

Not available yet. Open AuditionMusic5 in your phone browser instead.

Live chat

The chat button sits above the footer. Use it to reach the admin for account problems, payment questions, or song requests. You can also attach an image or file to your message.

VIP plans

VIP adds hidden and private server access, a larger playlist, and external song requests. Full pricing and payment steps are on the Plans page.

Supported servers

  • Indonesia - Audition AyoDance
  • Vietnam - Audition VTC Game
  • Thailand - Audition Playpark TH
  • China - Audition 9You
  • Korea - Audition Hanbiton
  • Taiwan - Audition MangoT5
  • Philippines - Audition Next Gen
  • Latin America - Audition Axeso5

Server availability can change. If a track or a whole list is missing, it may have been removed or renamed at the source.

Troubleshooting

A track will not play

Make sure you are logged in. Playback, MP3, and OGG are locked for guests.

The list is empty or a song disappeared

Switch server, then reload the page. If it is still missing, the source server probably removed or renamed the file.

Download does nothing

Downloads need a secure connection. Open the site over HTTPS, and allow downloads in your browser settings.

A song sounds wrong or is cut off

Report it in live chat with the song name and server. Include the exact title so it can be checked.
