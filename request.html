Request status and quota

Every request goes through these states:

StatusMeaning
PendingWaiting for the admin to review it.
ApprovedAccepted and queued for processing.
ProcessingBeing prepared for the catalog.
PublishedListed on the custom AuditionMusic5 server list.
RejectedNot accepted, with a short reason.
DuplicateThe song already exists in the catalog.
InvalidMissing or unusable source data.

Requests are counted per subscription period and reset at the start of every new period. Unused requests do not carry over. See the Plans page for the quota per plan.
